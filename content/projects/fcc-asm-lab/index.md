FCC ASM Lab is a browser-based assembly debugger designed for compiler construction courses. It runs SPIM/MIPS32 and RISC-V/RV32IM assembly locally in the browser, with no backend or separate simulator installation required.

## Features

- Source editing, breakpoints, stepping, step-over, and execution control.
- Register inspection and editing with hexadecimal, signed, unsigned, and binary formats.
- Stack, heap, and data-segment views with SP/FP stack-frame markers and little-endian memory display.
- Interactive standard input and output, plus built-in examples generated by the FCC compiler.
- Local browser storage for preserving the current program.
