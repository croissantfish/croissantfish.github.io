abstract: "Spatio-temporal forecasting is a fundamental task in urban computing, with applications ranging from traffic prediction to air quality forecasting. While numerous deep learning models have been proposed for this task, selecting and tuning the optimal model for a given dataset requires substantial domain expertise and manual effort. Automated Machine Learning (AutoML) has emerged as a promising direction to alleviate this burden. In this paper, we present EAST, an enhanced automated machine learning library specifically designed for spatio-temporal forecasting. EAST integrates a comprehensive search space of spatio-temporal architectures, an efficient search algorithm, and an automated hyperparameter optimization module. We demonstrate the effectiveness and efficiency of EAST through extensive experiments on multiple benchmark datasets, showing that it can discover competitive models with minimal human intervention."
