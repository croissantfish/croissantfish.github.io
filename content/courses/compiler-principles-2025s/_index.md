## Course Information

- **Course Name**: Principles of Compilation (编译原理)
- **Semester**: Spring 2025
- **Instructor**: Assoc. Prof. Songyu Ke (柯嵩宇)
- **Department**: College of Computer and Data Science, Fuzhou University
- **Audience**: Undergraduate students in Computer Science and Technology

## Course Description

This course systematically introduces the basic principles and implementation techniques of compiler construction. Through this course, students will understand how high-level programming languages are translated into machine-executable code, and master the design methods and implementation techniques of the core modules of a compiler.

Main topics include:
- Overall architecture and workflow of compilation systems
- Lexical analysis (regular expressions, finite automata)
- Syntax analysis (context-free grammars, top-down and bottom-up parsing)
- Syntax-directed translation and semantic analysis
- Intermediate code generation and optimization
- Target code generation

## Textbooks

- **Primary**: Alfred V. Aho et al., *Compilers: Principles, Techniques, and Tools* (Dragon Book), China Machine Press
- **Reference**: Andrew W. Appel, *Modern Compiler Implementation in C*
